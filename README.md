# Amazon Clone

A static, responsive web clone of Amazon's homepage featuring a modern design, dark mode, and a dynamic product grid.

## Features
- Responsive layout imitating the Amazon homepage.
- Modern CSS styling including dark mode.
- Dynamic product rendering from JSON data.
- Basic shopping cart functionality (Add to cart).

## Technologies Used
- HTML5
- CSS3 (Vanilla)
- JavaScript
